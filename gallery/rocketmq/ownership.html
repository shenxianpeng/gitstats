Code Ownership

Ownership is measured by how many commits each author made to each file of code in the current tree, its tests included, and to the same file under the names it had before. Documentation, vendored and generated files are left out. It highlights bus-factor risk (files only one person has ever touched) and where knowledge is concentrated. The bus factor is the smallest number of people who are, between them, primary owner of more than half of the files.
