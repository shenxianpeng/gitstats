Files that are both large and changed often are where bugs tend to cluster and where refactoring pays off first. Documentation, vendored and generated files, and files without counted lines, such as binary files, are left out.

Publishes the report to GitHub Pages on every push to main: turn on Pages for the gh-pages branch.

# .github/workflows/gitstats.yml
name: GitStats Report
on:
  push:
    branches: [main]
permissions:
  contents: write
jobs:
  gitstats:
    runs-on: ubuntu-latest
    steps:
      - uses: actions/checkout@v7
        with:
          fetch-depth: 0
      - uses: shenxianpeng/gitstats-action@v1
        with:
          deploy-to-pages: true
